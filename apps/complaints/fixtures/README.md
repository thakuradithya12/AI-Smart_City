# Demo complaint images

`demo-pothole.png` and `demo-streetlight.png` are original synthetic illustrations generated for this repository with Pillow drawing primitives and deterministic texture. They use no photographs, external images, datasets, or third-party assets, so there is no external source or licence to claim. Both images visibly say that they are illustrations and not real evidence. They exist only to exercise demo evidence upload/storage and must not be presented as real civic reports.
