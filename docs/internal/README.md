# Internal working notes

Files in this directory are project instructions, planning notes, deferred-work records, and owner decision tracking. They are working notes for project maintenance, not public user documentation, and are not served by the application.

- [AGENTS.md](AGENTS.md) — repository operating instructions and original scope/acceptance plan.
- [UNDERSTANDING.md](UNDERSTANDING.md) — initial repository analysis and planning notes.
- [PARKING_LOT.md](PARKING_LOT.md) — deferred work and unresolved external gates.
- [DECISIONS_NEEDED.md](DECISIONS_NEEDED.md) — owner questions and decision records.
- [CHANGELOG.md](../CHANGELOG.md) — dated repository change history.
